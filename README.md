# KAWS Archive

Projeto desenvolvido como uma experiência visual inspirada no universo artístico de **KAWS**, misturando arte, design, animações e elementos interativos.

O objetivo foi criar um site com uma estética mais imersiva e cinematográfica, fugindo de um layout tradicional de portfólio.

## Tecnologias

* HTML
* CSS
* JavaScript
* Higgsfield

## Principais recursos

* Animações durante o scroll
* Cursor personalizado
* Galeria de imagens
* Seções interativas
* Player de vídeo personalizado
* Layout responsivo
* Efeitos de parallax

## Vídeo

Uma das partes principais do projeto é a seção de vídeo, criada para complementar a experiência visual do site.

O vídeo utilizado no projeto foi produzido com o **Higgsfield**.

```text
video/higgsfield-film.mp4
```

## Como executar

Clone o repositório:

```bash
git clone URL-DO-REPOSITORIO
```

Entre na pasta do projeto e abra o `index.html` no navegador.

Também é possível utilizar um servidor local:

```bash
python -m http.server 5178
```

Depois acesse:

```text
http://localhost:5178
```

## Sobre

Este projeto foi desenvolvido para fins de estudo e portfólio, explorando principalmente **Front-end, UI Design, animações e experiências interativas na web**.
